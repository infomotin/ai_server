Security Guidelines

        
Configure security levels to control what the AI model can discuss.


        

            

                

                    

                        
                    

                    

                        
No Security

                        
Unrestricted responses

                    

                

                
The model responds without any content filtering. Best for private, trusted environments.

            


            

                

                    

                        
                    

                    

                        
Low Security

                        
Basic content filtering

                    

                

                
Filters harmful, illegal, and explicit content. Suitable for general use.

            


            

                

                    

                        
                    

                    

                        
Medium Security

                        
Standard protection

                    

                

                
Blocks weapons, hacking, drugs, self-harm, fraud. Recommended for business use.

            


            

                

                    

                        
                    

                    

                        
High Security

                        
Maximum restriction

                    

                

                
Family-friendly only. Blocks all controversial, political, and sensitive topics. Best for public-facing applications.

            

        


        

            
How Security Works

            
Security guidelines are applied via system prompts that instruct the model on what content to avoid. Create a restriction profile in the "Restriction Mode" tab to apply these guidelines.
