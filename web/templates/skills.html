Tips for Great Prompts

1. Set the Role

Start with "You are a [role]..." — this gives the AI a clear identity and expertise.

2. Define the Task

Clearly state what the AI should do — "Analyze...", "Write...", "Review...", "Explain..."

3. Set Rules

Add constraints — "Keep under 200 words", "Use bullet points", "Be professional".

4. Give Format

Specify output format — "Return as JSON", "Use markdown tables", "Number the items".

What Are Skills?

Skills are special instructions that change how your AI assistant thinks and responds. Think of them like giving your AI a new job title or expertise.

Without a skill, your AI is a general assistant. With a skill, it becomes a specialist — a code reviewer, a legal advisor, a creative writer, or anything you define.

Example:

Without skill: "How do I sort a list?" → Generic answer

With "Code Reviewer" skill: "How do I sort a list?" → Detailed code review with best practices, complexity analysis, and alternative approaches

How It Works (Step by Step)

1

You Create a Skill

Write a system prompt describing the AI's role, expertise, and rules.

2

Skill is Stored

The skill is saved with a unique ID in your collection.

3

You Use the Skill

Pass the skill ID when chatting. The AI receives the system prompt automatically.

4

AI Responds as Specialist

The AI follows the skill's instructions and responds in character.

WITHOUT SKILL

"Sure! Here's a review of your code..."

WITH "Code Reviewer" SKILL

User: "Review this Python code"

"## Code Review

### Issues Found:
1. Line 15: SQL injection vulnerability...
2. Line 23: Missing error handling...
### Suggestions:
..."

Structured, detailed, catches security bugs, gives actionable feedback

Why Use Skills?

Consistency

Get the same quality and format every time, not random outputs.

Expertise

Turn a general AI into a domain specialist with one prompt.

Time Saving

No need to explain context every time — the skill remembers.

Shareable

Share skills with your team via API — everyone gets the same AI behavior.
